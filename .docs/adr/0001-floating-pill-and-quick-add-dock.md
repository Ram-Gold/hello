# 1. Floating Pill Navigation and Companion Quick-Add FAB

In designing the bottom navigation for "Hello", we decided to float an organic rounded pill navigation container (`Home`, `People`) alongside an independent rounded-square Floating Action Button (`+`) on the same horizontal row, rather than using a full-width docked `NavigationBar`.

This layout optimizes for single-handed reachability on modern large Android devices, leaves the screen's bottom edges airy and unconfined to match the warm, tactile aesthetic of the app, and decouples navigation state from primary rapid-capture actions.
